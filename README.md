# Dreadcatch — Web Build

Compiled Unity WebGL build of **Dreadcatch**, hosted via GitHub Pages.
Play: https://octx29.github.io/Dreadcatch-Web/

A first-person horror salvage game. You are sent into an abandoned factory to
find hazardous waste containers, seal them, and carry them back to the boat
before the tide returns. Four container types each fail differently, the
shortcut runs through contaminated water, and the things in the dark listen.

This repository contains **build output only** (wasm, data, loader). Source code
is kept in a private repository. All content is proprietary — see [LICENSE](LICENSE).
Copying, redistributing, or re-hosting this build is not permitted.

Single-player only on web; co-op is available in the Windows build.
Plays on phones too (landscape): on-screen controls appear automatically on touch devices.
